What AbolKit does

AbolKit provides an accessible, embeddable video player as a standard custom element. Load the pinned CDN script, set a media src, and optionally attach caption tracks. Playback, seeking, volume, and caption UI ship with the component.

Features shown here

  • Video playback from a YouTube source
  • Play / pause, seeking, and volume via the built-in controls
  • Caption display from WebVTT files hosted with this site
  • Caption language selection (English and Amharic tracks)
  • Responsive layout that fills the page content width on desktop and mobile
