What AbolKit does

AbolKit provides an accessible, embeddable video player as a standard custom element. With caption-api and generate-captions, the player requests a transcript (and optional translations) for the video URL and attaches WebVTT tracks as they become ready.

Features shown here

  • Video playback from a YouTube source
  • Play / pause, seeking, and volume via the built-in controls
  • Captions generated via caption-api (not static VTT files)
  • English transcript plus Amharic translation when the API finishes
  • Responsive layout that fills the page content width on desktop and mobile
