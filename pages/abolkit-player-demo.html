What AbolKit does

AbolKit provides an accessible, embeddable video player as a standard custom element. Live caption generation uses the Abol Kit HTTP API (http://16.16.124.190/api) via caption-api + generate-captions. GitHub Pages stays on pre-generated WebVTT files because the API is HTTP-only (browsers block mixed content).

Features shown here

  • Video playback from a YouTube source
  • Play / pause, seeking, and volume via the built-in controls
  • Captions in English, Amharic, Afaan Oromo, Tigrinya, and Afar (generate-captions="am om ti aa" locally; static VTT on Pages)
  • Responsive layout for desktop and mobile

Caption modes (Option 1)

  • Local HTTP (live generation): python3 -m http.server 8000 then open http://localhost:8000/pages/abolkit-player-demo.html. The player calls caption-api="http://16.16.124.190" (API routes under /api).
  • GitHub Pages (HTTPS): uses pre-generated VTT under assets/media/hisys-story-*.vtt. Live generation is not attempted (no mixed-content bypass).
