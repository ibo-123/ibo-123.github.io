AbolKit player

Based on the Player (CDN) quickstart (@abolkit/player@0.1.1), with captions generated by the player from the caption API — not manual .vtt files.

What AbolKit does

Load the CDN script, drop in <abol-player>, set caption-api to the API origin and generate-captions for translation targets. The component calls http://16.16.124.190/api (lookup + generate), polls jobs, and attaches WebVTT tracks as they finish — English transcript plus Amharic, Afaan Oromo, Tigrinya, and Afar.

Features shown here

  • CDN install of @abolkit/player@0.1.1 (getting-started pattern)
  • YouTube playback with built-in play / pause / seek / volume
  • Captions generated via API: caption-api="http://16.16.124.190" + generate-captions="am om ti aa"
  • No captions= attribute and no manual <track> files

How to test caption generation

Serve over HTTP so the browser can reach the HTTP API (no mixed-content bypass): 

python3 -m http.server 8000
# open http://localhost:8000/pages/abolkit-player-demo.html

On GitHub Pages (HTTPS), the HTTP caption API is blocked by the browser. Live generation needs local HTTP until an HTTPS API endpoint is available.
