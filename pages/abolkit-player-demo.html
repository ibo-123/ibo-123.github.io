Try these controls

  1. Tab through controls; use Space/Enter to activate (keyboard access).
  2. Open CC → choose English or Amharic.
  3. Open Settings → Caption style (size, colors, position, edge).
  4. Toggle Sign language; drag the sign bar / grip to move or resize.
  5. Settings → Audio description (when a descriptions track is loaded).
  6. Use Download / offline-pack controls for the lightweight pack note.

Accessible job notices

<abol-job-card> renders a schema.org JobPosting (JSON, JSON-LD, or an HTML career page) as an accessible notice with a plain-language summary and an Apply control that opens in a new tab when a safe URL is present. This card uses inline JSON-LD — no extra request.

Low-bandwidth & offline

The player can expose a static offline pack URL (offline-pack) and a download control for Cache API offline playback. Packs are meant to stay small (audio, text, light HTML) for 3G and entry-level phones. This demo links a placeholder pack note from the package samples.

Caption API (optional, local HTTP)

Live caption generation uses caption-api + generate-captions against http://16.16.124.190 (routes under /api). Configure the origin with window.ABOLKIT_CAPTION_API before this script. HTTPS GitHub Pages cannot call the HTTP API (mixed content) — no bypass.
