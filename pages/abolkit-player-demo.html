AbolKit player

CDN quickstart from abolkit.vercel.app/getting-started (@abolkit/player@0.1.1). On local HTTP the player generates captions from the API; on GitHub Pages it uses pre-generated VTT (HTTPS pages cannot call the HTTP API — mixed content, no bypass).

What AbolKit does

With caption-api + generate-captions, the component calls http://16.16.124.190/api, polls jobs, and attaches WebVTT tracks (English transcript + Amharic, Afaan Oromo, Tigrinya, Afar).

Caption modes

  • Local HTTP (API generation): python3 -m http.server 8000 → http://localhost:8000/pages/abolkit-player-demo.html uses caption-api + generate-captions="am om ti aa" (no manual .vtt).
  • GitHub Pages (HTTPS): pre-generated assets/media/hisys-story-*.vtt only. Live API calls are not attempted.
